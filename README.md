# 물댄동산교회 3D 탐방

기존 Three.js 탐방 UI에 사용자가 첨부한 `3d-jutsu-2026-11-03-01-21-06.glb`를 연결한 정적 웹 앱입니다. 현재 모델은 `assets/church-environment-20261103.glb`에 원본 바이트 그대로 보관합니다. 별도로 업로드된 `assets/mdcc.glb`도 보존합니다.

층 기준은 B1 **-9.4m**, 1F **0m**, 2F **3.2m**, 3F **7.2m**, 4F **11.2m**입니다. 2층과 3층 구간은 각각 4m입니다. 본당 계단은 제거했으며 B1은 승강기로 이동합니다. 1F~4F 우측 계단과 전 층 승강기를 사용할 수 있습니다. 전체 보기에서는 원본 외관을 보고, 걷기에서는 시야를 가리는 개별 건축 부재만 잠시 숨깁니다.

## 실행과 조작

`python3 -m http.server 8001` 실행 후 http://localhost:8001 에 접속합니다. 빌드 과정은 없으며 Three.js 0.169.0을 jsDelivr에서 불러옵니다.

- ‘직접 걸어보기’: 전신 캐릭터로 탐방
- WASD / 방향키: 이동, 드래그: 회전, 휠: 줌
- 승강기 앞 E: 호출, 탑승 후 층 버튼: 이동
- Esc: 전체 보기, 공간 메뉴: 층으로 바로 이동
- 모바일: 화면 방향 버튼

## 검증

`npm install` 후 `npm test`로 모델 기하/동선 검사를 실행합니다. 로컬 서버와 Chromium이 실행 가능한 환경에서 `npm run test:browser`, `npm run test:camera`, `npm run test:occlusion`를 실행합니다. `CHROMIUM_PATH`와 `TEST_URL`로 경로를 변경할 수 있습니다. 브라우저 테스트는 CDN 요청을 동일 버전 로컬 Three.js로 응답합니다.

검사 결과와 스크린샷은 [검증 보고서](docs/verification/REPORT.md), `docs/verification/current/`에 있습니다. 기존 개략 모델의 과거 테스트 결과는 이번 모델의 통과 근거로 사용하지 않습니다.

## 정확도와 범위

외관의 십자가 정면 오른쪽 끝과 측면 유리의 방향을 유지합니다. B1은 넓힌 곡선 강단과 장의자 35개를 평바닥에 배치합니다. 런타임에서 내부 슬래브 개구부, 상부 계단참 연결, 승강기 문과 이동을 보완합니다. 십자가 타워는 외부 표면 위치를 유지하면서 내부를 비워 승강기 통로를 확보합니다.

PDF의 두 계단실 중 우측 코어를 이용하는 동선입니다. 좌측 1호 계단, 모든 실의 도면 좌표 정합, 1층 주차 배치의 상세 재현은 미완료입니다. 층 높이는 인계 기준이며 평면도만으로 설계 층고를 인증하지 않습니다. 가림 처리는 원본 부재 단위이며, 장의자는 한 개씩 묶어 처리합니다. 카메라가 항상 실내 경계 안에 머무르는 방식은 아닙니다.

GitHub Pages는 현재 저장소의 main/root를 게시합니다. 별도 Higgsfield/Sites 웹 체험판은 이 저장소 배포와 별개입니다.

## 2026-11-03 시야와 공간감 보완

같은 재질의 장의자 전체가 희게 흐려지는 문제를 수정했습니다. 화면을 가리는 원본 부재의 정점 범위만 숨기므로 나머지 좌석과 벽은 원래 색을 유지합니다. 실내 시야각 64°(근접 70°), 낮춘 카메라 내려다보기 각도, 환경광과 방향광 대비로 공간감을 조정했습니다. 건물 치수·외관 형상·좌석 수는 바꾸지 않았습니다.

## 본당 약 10m 공간감 / 사람 1.65m 기준 재구성

B1 바닥(-9.4m)에서 구조 천장(-0.4m)까지 실제 높이 9m를 사용해 약 10m의 공간감으로 구성했습니다. 캐릭터는 신발 바닥부터 머리끝까지 1.65m인 성인 체형입니다. 십자가 위 와이드 스크린은 폭 6.2m·높이 3.49m입니다. 본당 진입 시 강단과 스크린을 바라보며, 원본 GLB와 승인 외관을 유지합니다.

`npm run test:sanctuary`로 실제 브라우저의 모델 높이·사람 키·스크린/십자가 배치·본당 보행을 확인할 수 있습니다. `docs/verification/current/sanctuary-6m-165cm.png`에 수정 화면이 있습니다.

최신 환경 GLB의 `ROOF_Setback`이 회전해 본당까지 내려오는 오류는 원래 승인된 수평 지붕 위치(15.8~16m)로 복구했습니다. 주변 환경과 본당 비례는 유지합니다. `npm run test:roof`로 회귀 검사를 실행합니다.

## 참고 사진을 반영한 좌석·강단 보완

장의자를 총 35개로 구성했습니다. 벤치 한 개마다 좌판 4개와 앞뒤 등받이 쿠션을 나누고, 목재 프레임과 차분한 패브릭 색을 적용했습니다. 곡선형 객석 단차와 B1 계단은 제거해 하나의 평평한 본당 바닥으로 정리했습니다. 사진의 수백 개 독립 의자를 그대로 복제한 것은 아닙니다. 앞줄 3개는 강단과의 간격을 위해 조금 뒤로 옮겼습니다.

강단은 폭 10.8m·최대 깊이 4.4m의 곡선형으로 다시 만들고, 15cm 중간 발판으로 연결했습니다. 설교대 폭은 1.8배, 깊이는 1.35배로 넓혔습니다. 스크린 폭은 6.2m로 확대하고 강단 뒤 목재 마감과 3줄의 따뜻한 조명 트랙을 추가했습니다. 조명 기구는 시각 표현이며 실제 조도 설계가 아닙니다. `npm run test:layout`은 중앙 통로→강단 승하단→승강기 전실 보행을 검사합니다.

## 본당 뒤쪽 별도 공간

기존에 끊겨 있던 뒤쪽 벽을 자모실과 엔지니어룸의 연속 벽·공용 칸막이·천장으로 구성했습니다. 각 실은 본당을 바라보는 유리창과 별도 출입구가 있고, 문은 열린 상태로 고정돼 걸어서 출입합니다. 개구부 폭은 1.2m이며 문틀·문짝을 제외한 유효 폭은 약 1.1m입니다. 실 내부 높이는 약 3m, 본당 높이는 6m를 유지합니다.

자모실에는 소파·유아 매트·기저귀 교환대, 엔지니어룸에는 조정석·모니터·장비 랙을 배치했습니다. 사용자 지정 용도를 반영한 배치이며 도면의 유아실/방송실 위치와 정밀하게 정합한 설계 모델은 아닙니다. `npm run test:rooms`로 두 방 출입, 창/벽 충돌 및 승강기 접근 동선을 확인합니다.
