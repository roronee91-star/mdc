# 물댄동산교회 3D 웹 탐방 — 구현 버전

## GitHub Pages 배포

이 ZIP의 `index.html`과 `assets/` 폴더를 GitHub 저장소 `mdc`의 최상위에 업로드하세요. 기존 `index.html`은 별도로 백업하세요. 파일 구조:

```
index.html
assets/mdcc.glb
assets/stone-tile.webp
```

배포 주소: https://roronee91-star.github.io/mdc/

**중요:** 이전 GitHub 업로드에서는 `mdcc.glb`를 저장소 최상위에 올려두었습니다. 이번 코드는 `assets/mdcc.glb`에서 불러옵니다. `assets/` 폴더를 그대로 업로드해야 합니다.

## 제작 내용
- PDF의 지하 1층(B1)=본당, 지상 1층(F1)=필로티 주차장으로 대응
- 현재 확정한 꺾인 코너 외관은 `mdcc.glb` 그대로 유지
- GLB의 본당 강단/객석 좌표를 분석해 3D 장식, LED 스크린, 바닥 석재 패턴, 목재 패널 및 조명 추가
- 2층·3층·4층에는 임의의 새로운 방을 만들지 않고 최소한의 가구·등만 제안 요소로 추가
- 아바타, 카메라, 기존 짧은 이동 제한을 수정

## 근거와 한계
- 원본 PDF의 2페이지: **지하 1층 본당**, 3페이지: **지상 1층 필로티 주차장**, 4~6페이지: **지상 2~4층**.
- `mdcc.glb`는 이전 제작 과정의 개략 모델이므로 도면과의 구조·치수 완전 일치를 보장할 수 없습니다.
- LED, 목재 패널, 석재 텍스처, 강대상 물품은 **공식 확정 인테리어가 아닌 디자인 시안**입니다.
- 층 선택은 순간 이동 방식이고, 벽/가구의 정확한 충돌 또는 NavMesh와 멀티플레이는 아직 미구현입니다.
- CDN의 Three.js 라이브러리를 사용하므로 네트워크 연결이 필요합니다.

## 로컬 테스트

폴더 안에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 방문. `index.html`을 더블클릭해서 열면 GLB 로드가 막힐 수 있습니다.

## 2026-10 가상 탐방 업데이트

- 환영 화면, 층별 이야기, 9초 간격 안내 투어 및 중지
- 1인칭/아바타 시점 전환, 기존 키보드·모바일 조작
- 첨부 PDF에서 추출한 B1~4F 평면도 보기 (Esc로 닫기)
- 도면의 3층 식당·소그룹실 용도 반영 및 제안 식탁 배치

현재 웹 공간은 기존 `assets/mdcc.glb`를 기반으로 한 시제품입니다. 첨부된 `mdcc.blend`는 압축 해제 시 Blender 5.2 헤더를 가지며 설치된 Blender 4.3.2에서 열리지 않아 재수출하지 않았습니다. 도면과 모델의 정확한 치수·실별 위치 일치는 아직 검증되지 않았습니다. 가구와 마감은 제안입니다. 실시간 다중 접속, 벽 충돌, VR 헤드셋 지원은 포함되지 않습니다. 참고 사이트 inpeace.online은 작업 환경의 네트워크 정책으로 열람하지 못했습니다.
