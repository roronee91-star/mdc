# 물댄동산교회 — 3D 웹 탐방 시제품

업로드한 `mdcc.glb` 모델을 Three.js로 실제 불러오는 **1인용** 웹 탐방 앱입니다.

## 포함 파일
- `index.html`: 웹 앱 (별도 빌드 불필요)
- `assets/mdcc.glb`: 업로드한 Blender 모델 원본 그대로

## 실행
`index.html`을 더블클릭해서 여는 방식(`file://`)에서는 모델 로딩이 막힐 수 있습니다.

**간편 테스트**: 이 폴더에서 터미널을 열고:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 열기.

**GitHub Pages**: 새 저장소 또는 기존 저장소의 사이트 공개 폴더에 `index.html`과 `assets/mdcc.glb`를 **같은 폴더 구조**로 업로드하고, Settings → Pages → Deploy from a branch → `main` / `(root)` 선택.

## 조작
- 이름 입력 후 입장
- 전체 외관, B1 본당, 1F 필로티 주차장, 2F~4F 층별 전환
- `WASD` 또는 방향키 이동, `Shift` 빠르게, 마우스 드래그 시점 변경, 휠 확대/축소
- 모바일: 가상 조이스틱과 화면 드래그

## 범위와 주의
- 업로드된 실제 GLB를 사용합니다. 새 건물을 임의 생성하지 않습니다.
- 도면과 실제 건축 치수의 정합성은 아직 검수되지 않았습니다.
- 지하 1층 본당, 지상 1층 필로티 등 기존 모델 내의 배치도 **시안**입니다.
- 현재 층 선택은 모델 객체 이름(B1_, F1_, F2_, F3_, F4_)을 이용하여 다른 층을 숨기는 **층별 미리보기**입니다. 실제 층간 이동, 계단, 벽 충돌, 출입문 통과, 다른 성도와 실시간 동기화 및 채팅은 아직 없습니다.
- 앱은 외부 CDN의 Three.js 모듈을 불러오므로 인터넷 연결이 필요합니다.
- 원본 `.blend` 파일은 수정하지 않습니다.
