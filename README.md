# 물댄동산교회 — 내일을 걷다

첨부 건축 평면도와 외관 투시도를 참고해 새로 구성한 Three.js 건축 탐방입니다. 기존 `assets/mdcc.glb`는 보존하지만 새 앱에서는 불러오지 않습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8000` 실행 후 브라우저로 접속합니다. 빌드나 npm 설치는 필요하지 않습니다. Three.js 0.169.0 모듈은 cdn.jsdelivr.net에서 가져옵니다.

- 외관, 지하 본당, 2층 교육관, 3층 식당, 4층 외부 공간
- 전체 보기: 드래그 회전, 휠 확대
- 걷기: WASD/방향키, 드래그 시선, 모바일 방향 버튼; Esc로 전체 보기
- 벽·좌석·주요 가구의 단순 충돌 처리
- 실제 첨부 도면 이미지와 비교

## 모델 근거와 정확도

`src/app.js`에서 미터 단위로 건축 요소를 생성합니다. B1 외곽 26.6 × 22.4m, 상부 기준 24.85 × 18.45m는 도면 치수에서 읽었습니다. 본당은 도면의 좌측 상단 강단과 부채꼴 좌석 방향을 반영했습니다. 외관의 석재 타워, 십자가, 수직 루버와 유리 입면은 사용자 투시도를 참고했습니다.

층고, 실별 상세 경계, 문·계단, 좌석 수, 외부 대지·주변 건물은 정밀 측량·설계 모델이 아닙니다. 실내 마감·조명·가구·식재는 제안입니다. 상부층은 용도를 반영한 개략 공간이며 도면의 모든 실을 정확히 재현하지 않았습니다. 계단으로 이어지는 연속 이동, 다중 접속, VR 헤드셋은 미구현입니다.

물리 기반 재질, 시드가 고정된 표면 텍스처, 환경 반사, 그림자을 적용했습니다. 사진 수준의 사실성을 보장하지 않으며 실사 재질·정밀 디테일·간접광 베이킹을 추가할 여지가 있습니다. SSAO 후처리는 실행 환경의 빈 화면 문제로 제외했습니다. 정적 메시는 재질별로 합쳐 렌더링 호출을 줄입니다.

첨부 Blender 파일은 Blender 5.2 헤더로 현재 설치된 4.3.2에서 열리지 않았습니다. 해당 파일을 변환했다고 주장하지 않습니다. 새 웹 모델은 기존 GLB와 독립적으로 생성됩니다.

`src/style.css`: 데스크톱/모바일 인터페이스. `assets/plans`: 첨부 PDF의 층별 도면. GitHub Pages는 main / root 기준으로 제공할 수 있습니다.

## 높은 본당 디자인 제안

새 참고 이미지의 분위기를 반영해 본당 내부 높이를 약 10.8m로 설정했습니다. 이는 사용자의 높은 층고 요청에 따른 디자인 가정이며 PDF 단면도에서 확인한 수치가 아닙니다. 외관 층별 높이와의 구조적 정합은 아직 검증하지 않았습니다. 목재 천장, 벽체 흡음 패널, 간접조명, 매달린 조명 레일, 대형 LED 화면 및 목재 팔걸이를 추가했습니다. LED의 산 풍경은 코드로 그린 원본 그래픽입니다. 참고 이미지의 교회명과 층별 용도는 그대로 복사하지 않고 기존 프로젝트명과 PDF의 용도를 유지했습니다.

본당 비례 재검토: 좌석 폭 48cm, 등받이 상단 약 85cm의 얇은 패브릭 좌석과 목재 프레임으로 교체했습니다. LED 화면은 약 12.3 × 5.6m로 확대했습니다. 추천 시점은 1.65m 눈높이이며 메뉴를 접어 강단이 가려지지 않게 했습니다. 10.8m 천장고는 사용자의 공간감 요청에 따른 시각화 가정입니다.

계단식 객석 검토안: 12열, 열 간격 0.92m, 단차 0.12m(최대 1.32m). 사용자의 추정에 따른 제안이며 단면도 확인 전입니다. 보행 높이도 객석 단차를 따릅니다. 추천 카메라는 단상 뒤가 아닌 객석 통로에서 강단을 바라봅니다.

게시본 사용성 개선: 계단 통로 단차 표시등, 항상 보이는 ‘직접 걸어보기’ 버튼, 메뉴 펼침 상태 접근성, 작은 화면의 스크롤 가능한 메뉴를 추가했습니다. `.nojekyll`을 포함해 GitHub Pages가 정적 파일을 그대로 제공합니다.
