# 2층 소예배실 — 앞 벽 스크린

요청: "소예배실 앞에도 스크린으로 바꿔줘" → "스크린 안엔 이걸 해줘" (사용자가 준 그림: '서로 짐을 나눠지는 공동체')

## 바꾼 것 (index.html, 2층 소예배실 블록)
- 앞(북쪽) 원목 벽 가운데에 본당처럼 검은 테두리 화면을 걺: 16:9, 2.3m × 1.29m, 아래 끝 바닥에서 0.74m (강대상 윗면 0.44m보다 위라 가리지 않음)
- 화면 그림: 사용자가 준 그림을 1280×720 JPG로 줄여 `assets/screen/share-burdens.jpg`로 넣음 (못 불러오면 같은 글씨를 코드로 그린 그림)
- 십자가는 화면 오른쪽(동쪽) 벽 x -7.75로 옮기고(크기·높이 그대로), 뒤에 은은한 빛 (밤에 더 밝음). 왼쪽은 디지털 피아노
- 화면 판은 누르기·걷기·카메라 판정에서 빠짐
