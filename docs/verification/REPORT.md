## 검증 방법

`current/structure-results.json`: Node/Three.js에서 16개 검사 통과. 닫힌 승강장 문의 진입 차단, B1↔4F 연속 상하행, 5개 층 계단참→승강기 접근, 5개 층 승강기 운행/하차/재탑승, 보호 메시 보존, 타워 외부 표면 보존, 1F 측면 진입을 검사한다.

`current/browser-results.json`: 19개 검사 통과, 페이지 JavaScript 오류 0개. 실제 Chromium에서 키보드/포인터 입력을 사용한다. 소프트웨어 GPU 속도와 이동 거리를 분리하기 위해 `?test`의 고정 시간 간격으로 프로덕션 이동·충돌·승강기 코드를 실행한다. 고정 시간 검사에서는 화면 갱신 시 카메라를 현재 캐릭터 위치에 즉시 맞춘다. 일반 실시간 모드의 카메라는 별도 `current/camera-live-results.json`으로 검사한다. 결과 파일이 생성되지 않은 실행은 통과로 간주하지 않는다.

스크린샷은 `current/`에 저장한다. 테스트는 CDN을 같은 버전의 npm 파일로 응답하며 WebGL은 소프트웨어 렌더링이다. 소프트웨어 GPU에서는 Lambert 재질/투명 유리, 낮은 해상도, 최대 12fps로 전환하고 환경 반사와 그림자를 끈다. 일반 GPU에서는 원본 재질과 환경 조명을 유지한다. 하드웨어 성능 또는 모든 환경에서의 CDN 접속을 보장하는 검사가 아니다.

## 남은 범위

- 모든 위치에서의 카메라 가림/충돌 전수 검사. 최소 거리보다 좁으면 표면을 투명화하며, 같은 재질 배치 전체가 투명해질 수 있다. 카메라가 항상 벽 안쪽에 머문다고 주장하지 않는다.
- 구조 안전성, 건축법/피난 기준의 적합성 검증은 수행하지 않았다.

직접 확인한 스크린샷: `current/stair-arrival-3.png`의 계단참 전신 시점, `current/04-lift-b1.png`의 승강기 탑승 시점, `current/05-mobile-full-body.png`의 세로 화면.

## 배포 검증

배포 대상은 사용자가 지정한 현재 저장소의 GitHub Pages(main/root)다. 게시 주소 직접 접속은 실행 환경 프록시의 CONNECT 403으로 차단되므로, 실제 공개 URL의 브라우저 검사는 수행하지 못했다. 배포 여부는 GitHub Pages 워크플로 결과로 별도 확인한다.
