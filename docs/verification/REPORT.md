이전 승인 모델 `assets/church-v13.glb`에서 원래 변환을 확인했다. 웹에서 해당 지붕 하나의 위치를 (0,15.8999996185,-6), 회전을 단위 quaternion, 축척을 1로 복구했다. 복구 후 지붕은 수평이며 높이 15.8~16m, X±12.425m에 놓인다. 최신 GLB와 주변 환경은 유지하고 원본 파일 바이트는 수정하지 않았다. 본당 6m/사람 1.65m와 스크린도 유지했다.

기하/동선 검사 17개 통과(지붕 범위 검사 추가), 외관·본당·주변 환경 보호 대상 760개 메시 보존 확인. 실제 Chromium 회귀 검사 `tests/roof-regression.cjs`에서 지붕 위치/회전, 환경 객체 유지, 본당 객석 위 수직 레이의 지붕 비간섭, 페이지/셰이더 오류를 확인한다. 결과와 스크린샷은 `current/roof-regression-results.json`, `roof-fixed-exterior.png`, `roof-fixed-sanctuary.png`에 기록한다. 이전 전체 브라우저 동선 19개를 이번 수정 후 재실행한 것은 아니다.

지붕 브라우저 회귀 검사 통과: 주변 환경 객체 510개 유지, 본당 객석 위 레이 간섭 없음, 페이지/셰이더 오류 0개. `roof-fixed-sanctuary.png`와 `roof-fixed-exterior.png`를 직접 확인했다.
