# 객체 검사 및 제한 수정

현재 런타임 모델 2,102개 메시를 검사했다. 원본 GLB 파일은 변경하지 않았다.

## 확인 후 수정한 객체

`B1_Pew_38`은 `B1_Pew_33`과, `B1_Pew_39`는 `B1_Pew_32`와 동일한 위치의 중복이다. 중복 생성만 제거했다. 외관·층고·벽·가구 배치는 변경하지 않았다. 실제 보이는 벤치 위치는 그대로이며 객체 수는 37세트에서 35세트가 된다.

삭제된 객체는 각 접두사 `B1_Pew_38_`, `B1_Pew_39_`에 아래 접미사를 붙인 총 32개다.

- `Back`, `Seat`, `Leg1`, `Leg-1`
- `Cushion_0`, `Cushion_1`, `Cushion_2`, `Cushion_3`
- `Upholstery_0`, `Upholstery_1`, `Upholstery_2`, `Upholstery_3`
- `RearUpholstery_0`, `RearUpholstery_1`, `RearUpholstery_2`, `RearUpholstery_3`

## 검사 범위와 한계

- 월드 좌표에서 동일 삼각형 검사: 중복 좌석 면 제거 확인. 벽/슬래브 접합부의 일치 삼각형은 별도 후보로 JSON에 기록하고 유지했다. 모든 부분적 공면 중첩을 탐지하는 검사는 아니다.
- 실내 가구의 Leg/ChairBase 하단 지지 레이: 지지 누락 검출 0. 천장 매달림 부재 등 모든 컴포넌트의 구조 연결을 검증한 것은 아니다.
- 가구와 벽/유리 경계 상자의 5mm 이상 겹침 후보: 검출 0. 이름 기반 분류 범위에 한한다.
- 메시 부호 체적의 음수 검사: 검출 0. 개별 삼각형의 국소 뒤집힘이나 열린 메시의 방향을 보증하지 않는다.
- 구조/동선 회귀 검사 23개 통과. 후속 Chromium 재검사에서 전체 동선 17개 통과, 본당 35세트/강단 접근/승강기 통로 통과, 좌석 가림 재현 검사 통과. 페이지 오류 0개. 갱신된 `expanded-sanctuary.png`를 직접 확인했다. 공개 Pages URL 직접 접속은 환경 프록시 403으로 확인할 수 없었다.

상세 수치는 `mesh-audit.json`, 검사 코드는 `tests/mesh-audit.mjs`에 있다.
