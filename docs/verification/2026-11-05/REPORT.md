## 고친 것
1. 지하 이름표(자모실·방송실)가 1층·3층 화면에서 땅을 뚫고 보이던 것 → 그 층을 볼 때만 보이게.
2. 3층 소그룹실 1이 건물 돌기둥(RIGHT_STONE_END_PIER, x -1.04~0.21, z -17.1~-15.1)에 반쯤 묻혀 있던 것
   → 기둥 남쪽부터 소그룹실 3개를 같은 깊이(약 2.3m)로 다시 나눔. 기둥 옆 좁은 자리는 '창고'.
3. 소그룹실 식탁: 0.9×0.5m, 의자 4개. 식탁 둘레 통로 0.65m 이상 → 문 반대편 의자까지 돌아 들어감.
4. 주방 조리대가 북서쪽 돌기둥(BACK_STONE_FIN)과 겹치던 것 → 남쪽으로 줄이고 폭 1.6m로 (양옆 통로 0.9m 이상).
5. 소그룹실 앉기 시 카메라가 벽 너머에 있어 캐릭터가 가려지던 것 → 방 안에서 비춤.

## 이동성 검사 (tools/walk-check, 몸 반지름 R 기준 격자 탐색)
- 3층: 식당 의자 54 + 소그룹실 의자 12 + 주방·배식대·화장실·창고 = 71곳, R=0.28·0.30 모두 71/71 도달.
- 지하 본당: 의자 112석 앞자리 + 무대·자모실·방송실 = 118곳, R=0.28에서 117/118 (못 간 1곳은 방송 데스크 안쪽에 찍은 검사점이라 문제 아님).
  단, R=0.35(몸 폭 0.7m)이면 의자 줄 사이가 좁아 51/118만 도달 → 줄 사이 실제 틈은 약 0.7m.
- 캐릭터는 여전히 벽·가구와 충돌하지 않음(클릭한 곳으로 직선 이동). 위 검사는 "지나갈 틈이 있다"는 뜻.
