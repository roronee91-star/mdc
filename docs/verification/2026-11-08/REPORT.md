# 2층 소예배실 의자 — 원목 틀 + 초록 가죽

요청: 사용자가 보여 준 교회 의자 사진 "소예배실 의자는 이런 컨셉으로 변경" (분위기만 참고, 그 제품 모양을 그대로 따르지 않음)

## 바꾼 것 (index.html, 소예배실 블록)
- 개인 의자 30개(5줄 × 6, 자리 그대로): 밝은 원목 틀 + 초록 가죽 방석·등받이, 등받이 아래 원목 띠와 들어간 원목 판, 위 원목 띠, 뒤로 살짝(0.1 rad) 기운 등받이 기둥, 앞다리·옆/앞/뒤 띠
- 앉는 높이·크기는 예전과 같음(윗면 0.20m, 폭 0.30m), 앉으면 기도(kind 'pew') 그대로
- 가볍게: 의자마다 2조각(원목 · 초록)이고 30개가 같은 모양을 함께 씀 (예전 의자는 8조각씩 240조각)
- 세운 등판이 어둡게 보여 초록에 약한 자체 밝기를 더함

## 확인 (tools/walk-check/chapel.cjs)
- 화면 오류 없음
- 앉을 자리 30개 모두 잡힘, 눌러서 앉으면 의자 자리에 정확히 앉고(거리 0) 기도 자세(눈 감음)
- 사진: chapel-rows.png(소예배실 전체), chapel-close.png(앞에서 가까이), chapel-side.png(옆모습)

## 이어서: "마음에 안 든다 — 투박하다(2번)" → 날씬하게
- 앞다리 3.2cm → 2cm, 뒷기둥 3.4 × 3.6cm → 2.2 × 2.4cm, 띠 4.5 × 2.4cm → 3 × 1.4cm, 방석 4.2cm → 2.8cm, 등판 3cm → 1.8cm, 위 띠 4 × 3.6cm → 2.6 × 2.4cm, 둥근 모서리 6mm → 4mm
- 등받이 윗면 0.527m → 0.47m (사진 비율에 가깝게), 앉는 높이 0.20m 그대로
- 확인: 화면 오류 없음, 앉을 자리 30개, 눌러서 앉으면 정확히 앉고 기도 자세. 사진(덮어씀): chapel-rows.png, chapel-close.png, chapel-side.png

## 이어서: "가운데 판자가 왜 있는지 모르겠어" (사용자가 등받이 아래에 동그라미)
